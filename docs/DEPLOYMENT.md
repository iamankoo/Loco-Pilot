# Deploying LocoPilot

- **Frontend** → Vercel, project `loco-pilot` → https://loco-pilot.vercel.app
- **Backend** → Render, Blueprint in `render.yaml` (API + Postgres/pgvector + Redis)

## Backend (Render)

1. Render dashboard → **New → Blueprint** → pick this repo and the `deploy` branch.
2. When asked for secrets, enter `LLM_API_KEY` and `EMBEDDING_API_KEY` (your NVIDIA key).
3. After the first deploy, open the `locopilot-api` service → **Environment** and copy `ACCESS_TOKEN`
   (generated by Render). That is the token the website asks for.
4. Note the service URL (`https://locopilot-api.onrender.com`, or whatever Render assigned).

`CORS_ORIGINS` in `render.yaml` must include the frontend origin.

## Frontend (Vercel)

Root directory `frontend`, framework Next.js, env var
`NEXT_PUBLIC_API_BASE_URL=<the Render service URL>` (no trailing slash).
It is a build-time variable: change it → redeploy.

## Access token

The backend rejects `/api/*` requests without `Authorization: Bearer <ACCESS_TOKEN>`. The site prompts for the
token once and keeps it in that browser's localStorage. Unset `ACCESS_TOKEN` (local development) and no prompt appears.

## Saving files to your computer

Before a run, the site asks you to pick a folder (browser permission prompt). When the run finishes, the project
is copied to `<chosen folder>/<project-name>/`. Requires a Chromium browser (Chrome, Edge). The server's copy is
temporary on Render (`/tmp`), so the local copy is the durable one.

## Limits on Render

- No Docker daemon: the isolated test sandbox and "Running Locally" preview don't work there; they do locally.
- Free plans: the API sleeps when idle (about a minute to wake), free Postgres expires after 30 days.
